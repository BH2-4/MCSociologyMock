# 面向市场实验的 LLM 多智能体微型社会：系统性文献调查

生成日期：2026-07-24（Asia/Shanghai）  
核心文献：35 篇；同行评审论文/会议论文：32 篇（91.4%）；工作论文或预印本：3 篇；另列 1 篇背景性同行评审文献、1 部背景著作和 6 篇用户提供的全文补充（5 篇有正式期刊版本，1 篇为 workshop/arXiv 稿）  
总体置信度：关于“单个 Agent 不足以构成社会模拟”的判断为高；关于 LLM Agent 可用于机制探索的判断为中；关于其现实市场定量预测能力的判断为低。

## 1. 执行摘要

### 直接答案

文献不支持把“一个带提示词和钱包的 LLM Agent”视为最小的**社会**模拟单元。Agent 是实现单位和行动单位，但市场结果由行动、交易机会、制度约束、信息结构和结算共同生成。适合本项目的工作定义是：

> **最小可行社会模拟单元 = 至少两个异质行动者 + 有条件的交换机会/关系 + 共享环境 + 可执行的制度约束 + 信息/声誉状态 + 一次可观测、可结算并反馈到后续状态的事件。**

可形式化为一个状态转移：

`(A, X, N, E, I, H, M)_t --event/action--> (A, X, N, E, I, H, M)_{t+1} + audit log`

其中 `A` 是行动者状态，`X` 是可交换资源与机会，`N` 是含替代性、排他性和容量的关系/交换网络，`E` 是市场、空间和时间，`I` 是产权、预算、匹配与制裁规则，`H` 是双边历史、公共声誉与证据来源，`M` 是货币、信用或其他结算状态。关系社会学反对把行动者视为脱离关系的实体；ABM 文献要求由微观互动生成宏观结果；交换网络实验进一步表明，边之间是否相互替代或使另一笔交易成为可能，会改变权力分配，不能压缩成节点属性 [R01, R03-R05, S03]。

这一定义仍不是已有学术术语，也不是普适的“最小社会”。二元关系能形成最小互动，但 Cook 等指出，两条共享行动者的二元关系只有在一条关系中的交换取决于另一条关系中的交换/不交换时，才构成交换网络 [S03]。三角闭合、联盟、群体边界、替代交易伙伴和市场竞争至少要求相互连接的多条关系。MVP 因而需要一个**行动者集合和有机制语义的交换图**，而不是一个二人对话或普通社交图。文献没有给出适用于所有问题的最小 Agent 数量；数量应由目标机制、网络结构、统计功效和运行成本决定。

### 最强证据

1. Macy 与 Willer 把 ABM 的优势定位为解释“局部关系层面的微观基础如何生成非平凡宏观模式”；动态网络既塑造互动也被互动重塑 [R03]。
2. Sawyer 明确区分微观到宏观的涌现、宏观到微观的社会因果，以及二者循环，因此制度和环境不能全部压缩成个人提示词 [R04]。
3. Windrum 等把 ABM 的共同成分概括为异质行动者、有限理性、直接网络互动和路径依赖，并指出验证必须把理论、模型和现实数据联系起来 [R10-R12]。
4. Park 等证明记忆、反思和规划能增加行为的“可信感”，但其评估目标是 believability，不是市场预测准确性 [R24]。
5. Larooij 与 Törnberg 的系统综述发现，LLM 的黑箱性、文化偏差与随机性可能加剧 ABM 的验证问题；许多研究仍停留在表面效度或松散的结果对齐 [R29]。
6. Xie 等 2026 年的 SSDataBench 发现，当前 LLM 在稀疏条件下会把现实异质性压缩成较简单的类型结构 [R32]；Seshadri 等还发现模拟用户会发生系统性校准误差和群体差异 [R33]。
7. Gode 与 Sunder 的双向拍卖中，受预算/不亏损约束的随机交易者平均配置效率为 98.7%，人类市场为 97.9%；但随机交易者的价格收敛更慢、波动和利润离散更大 [S02]。这说明高配置效率可能主要来自制度约束，不能归因于 Agent “聪明”或“像人”。
8. Cook 等的 100 人实验和多规模仿真显示，交换权力来自替代伙伴和结构依赖；一般的接近/中介中心性在负连接交换网络中会误判权力 [S03]。Greif 的历史分析与 Bolton 等的 144 人实验则表明，声誉机制依赖身份持续、信息流、未来机会损失和制裁边界，公共反馈不能等同于直接重复关系 [S04-S05]。
9. Jiang 等的理论与实验把货币“必要”限定为：有货币时可激励实现的结果严格优于无货币机制；双重需求巧合、有限承诺与历史/信息摩擦缺一不可 [S07]。因此钱包不是原始社会构件，原始构件是稀缺状态、可执行转移和针对具体摩擦的结算机制。
10. Jia 与 Yuan 的 22 个 GPT-4 会话、五轮双向拍卖没有显示单调价格稳定，但成交均价接近理论价格、五轮中四轮达到预测数量；该设计没有独立重复、人类对照、配置效率或统计检验 [S06]。它不能支持“LLM 无法达到市场均衡”的一般结论，只能作为一个受限提示/反馈设计的初步结果。

### 能做与不能做

| 用途 | 当前适用度 | 判断 |
|---|---:|---|
| 机制探索 | 高 | 可比较“某组规则是否足以生成某种模式”，但不能据此证明机制真实 |
| 情景比较 | 中 | 在相同校准人口、网络和模型版本下比较干预方向；必须做多随机种子和敏感性分析 |
| 产品创意/风险预演 | 中 | 可暴露可能的传播路径、激励冲突和异常情景，不能替代用户研究 |
| 定量市场预测 | 低 | 缺少真实人口、偏好、网络、交易和干预响应数据时，销量、价格弹性和份额数字不可外推 |

## 2. 概念比较

| 理论传统 | 基本分析单位 | 核心机制 | 可观测变量 | MVP 含义 | 主要局限 |
|---|---|---|---|---|---|
| 方法论个体主义/分析社会学 | 行动者与行动 | 个体欲望、信念、机会产生行动并聚合 | 选择、资源、信念、行动 | Agent 必须有可操作状态和决策规则 | 容易低估关系、制度和意义结构 |
| 关系社会学 | 交易、关系和关系场 | 行动者及身份由持续关系构成 | 互动频率、关系类型、权力、信任 | 关系图必须是一等状态，不能只是聊天记录 | 难直接给出计算实现与参数 |
| 符号互动/角色理论 | 情境化互动与角色 | 意义在互动中解释和协商 | 角色、定义情境、符号、期待 | 同一 Agent 在不同角色/场景下应有不同权限和规范 | 测量与校准困难 |
| 结构化理论 | 实践中的行动者与规则/资源 | 结构既约束行动，也是反复实践的媒介和结果 | 规则调用、资源使用、规则再生产/改变 | 制度必须在事件中被执行；后续版本可让规则被实践改变 | 难直接转化为可识别参数和因果检验 [S01] |
| 微观—宏观机制 | 跨层状态转移 | 局部互动涌现宏观结构，结构再约束个体 | 个体事件、网络、群体统计 | 同时记录微观事件和宏观指标，并允许反馈 | 一个宏观模式可能由多种机制生成 |
| 传统 ABM | 异质、有限理性的 Agent 网络 | 局部规则、学习、网络互动、路径依赖 | 状态、行动、网络和时间序列 | 规则应明确、可消融、可重复，而非全部交给 LLM | 行为规则可能任意，经验校准困难 |
| 交换网络/权力依赖 | 相互连接的交换关系与位置 | 替代伙伴、机会成本、正/负连接、结构依赖 | 报价、成交、剩余分配、关系容量、移除节点后的流量 | 边必须记录交换条件；权力用剩余和反事实依赖度量 | 经典实验多为高度简化的负连接网络 [S03] |
| 生成式 ABM | LLM Agent + 外部状态与工具 | 自然语言推理、记忆、规划和互动 | 结构化理由、对话、行动、工具调用 | LLM 负责有限决策，状态和制度由确定性引擎维护 | 黑箱、随机、模型漂移、文化偏差、复现成本高 |
| 制度/博弈论 | 博弈位置、规则和重复互动 | 激励、声誉、惩罚、互惠、规则演化 | 收益、合作、违约、制裁、声誉 | 预算约束、支付矩阵、执行与制裁必须显式 | 简化博弈未必对应现实市场 |

## 3. 六组证据地图

### 3.1 社会学基础

- Emirbayer 的关系社会学把关系和交易过程置于实体属性之前 [R01]。设计含义：关系不是 Agent prompt 中的静态描述，而是能被事件更新、能影响后续行动的状态。
- Granovetter 的阈值模型表明，相近的个体偏好分布可能因互动序列和阈值差异产生完全不同的集体结果 [R02]。设计含义：必须保存曝光、邻居行动和采用阈值，不能只看总体情绪。
- Macy、Willer 与 Sawyer 把 ABM 的社会学价值放在关系层面的微观基础和跨层反馈上 [R03-R04]。
- Giddens 的结构化理论把规则/资源看作行动的媒介与结果：制度不只是顶层约束，也在重复实践中被再生产 [S01]。MVP 可先固定制度，但事件日志应保留未来研究制度变化所需的规则调用与争议记录。
- Epstein 的“生成式解释”只说明一组规则足以产生结果，不证明这组规则是现实中的必要原因 [R05]。这是本项目避免过度宣称的核心边界。
- Hedström 与 Ylikoski 强调机制解释、行动理论和中层理论；LLM 输出应受明确机制假设约束，而不是自由即兴 [R08]。

### 3.2 传统 ABM、描述与验证

- ODD/ODD 更新协议要求分开描述模型概览、设计概念和实现细节，有利于复现和模型比较 [R09-R10]。
- Windrum、Fagiolo 与 Moneta 讨论间接校准、Werker–Brenner 和 history-friendly 等路径，没有单一验证法适用于所有目的 [R11-R12]。
- An 的综述显示，人类决策规则可以来自效用、启发式、认知、学习或经验数据；选择哪一种必须与研究问题和校准数据匹配 [R13]。
- 对本项目而言，验证对象至少分四层：个体选择、互动过程、网络/市场中观结构、宏观结果。只让评审觉得对话“像人”属于最低等级的表面效度。

### 3.3 市场、产品采用与扩散

- Rand 与 Rust 要求营销 ABM 在理论、数据、实现、验证和报告上保持严谨 [R14]；Kiesling 等的综述显示创新扩散模型通常需要异质消费者、决策规则、社会网络、沟通渠道和供给侧因素 [R15]。
- Watts 与 Dodds 的模拟对“找少数意见领袖即可引爆市场”提出限制：在很多条件下，大级联更多依赖一批容易受影响的个体，而非极少数超级影响者 [R16]。
- Delre 等和 Goldenberg 等把促销时间、目标选择和口碑视为网络中的动态过程 [R17-R18]。产品实验应操纵曝光位置与时机，而不是只改变 Agent prompt。
- Gode 与 Sunder 在五个双向拍卖市场中比较人类、无约束随机交易者（ZI-U）和受预算约束随机交易者（ZI-C）。ZI-C 平均配置效率 98.7%，人类为 97.9%，而 ZI-U 随市场供需形状在 48.8%–90.0% 之间；同时 ZI-C 的价格收敛慢于人类、价格和利润分布更不稳定 [S02]。**论文结论：**市场纪律可替代部分个体理性。**综合判断：**配置效率、价格稳定、分配公平和信息学习是不同结果，不能以一个“接近均衡价”的指标替代。
- Cook 等把交换网络定义为行动者、价值资源、交换机会、实际关系及关系间连接。其五人负连接网络实验使用 100 名大学生、27 个议价期；配套仿真把简单适应行动者扩展到 5/7/10/13 节点、每种结构 50 次重复。收益分配支持权力—依赖预测，而普通接近/中介中心性未能识别关键位置 [S03]。**设计含义：**交易边要记录替代性、正/负依赖、容量和排他性；市场权力要观察议价剩余以及移除节点/替代伙伴后的反事实，而不只报告中心性。
- Jia 与 Yuan 的五轮 GPT-4 双向拍卖报告理论价格 2，五轮均价为 2.04、2.20、2.11、2.12、2.02，预测成交量均为 6，实际为 6、5、6、6、6 [S06]。论文把非单调稳定解释为 LLM 未收敛，但没有报告配置效率、独立重复、统计检验或本研究内人类对照。**综合判断：**该结果提示需要更完整的历史/学习设计，却不能证明 LLM 一般性地“不能达到市场均衡”。
- 推荐结果指标：采用率、首次采用时间、扩散曲线、级联规模/深度、转化率、复购、价格弹性、成交量、消费者剩余、财富分布、网络模块度和结果方差。

### 3.4 博弈、规范和制度

- Axelrod 的演化模拟显示规范需要执行机制；“元规范”解释了惩罚不执行规范者如何支持稳定性 [R19]。
- Ostrom 强调条件合作者、愿意惩罚者、群体和规则的异质性 [R20]；Fehr 与 Gächter 的实验说明即使惩罚有成本，惩罚也可维持公共品合作 [R21]。
- 间接互惠依赖声誉信息 [R22]；Young 说明规范可通过反复互动、学习和演化形成 [R23]。
- Greif 结合契约/声誉理论与 11 世纪开罗 Geniza 商业文书，说明 Maghribi 商人联盟如何借由监测、贸易通信、未来雇佣溢价和集体排斥降低代理交易成本 [S04]。这种制度同时依赖并再生产群体身份，而且把信任限制在联盟边界内，产生排斥和市场分割；作者明确把制度普遍性留作待研究问题。
- Bolton、Katok 与 Ockenfels 的 144 人、30 轮实验比较陌生人随机匹配、带真实卖家历史的反馈市场和固定伙伴市场。效率、信任（购买）和可信行为（发货）均满足“陌生人 < 反馈 < 伙伴”；反馈效率是陌生人 2.8 倍，伙伴又是反馈 1.8 倍 [S05]。相同声誉内容未让间接互惠达到直接重复关系的效果；一次负面经验对全市场信任的侵蚀大于正面经验的建设，并且自动真实反馈高估了现实自愿反馈系统。
- **综合判断：**信任、声誉、制裁和规则不能只存在于自然语言对话中，也不能合并成单一声誉分数。环境应分别维护双边历史、公共反馈、证据来源/时效、市场层信任、身份持续性、成员边界和制裁可达范围 [S04-S05]。

### 3.5 LLM 多智能体社会模拟

- Park 等的 25 Agent 沙盒使用观察、记忆检索、反思和规划；消融表明这些部件提升行为可信感 [R24]。这支持 Agent 内部状态，但不验证人口代表性。
- Aher 等的 “Turing Experiments” 重现实验时发现部分经典效应，同时发现 “hyper-accuracy distortion” [R25]；Argyle 等说明人口画像条件化可改善群体响应相似度，但结果仍受模型和提示影响 [R26]。
- Horton 等把 LLM 当作可赋予禀赋、信息和偏好的 “Homo silicus”，适合生成和压力测试经济假设，而非默认替代人类 [R27]。
- Jia 与 Yuan 的初步实验进一步暴露了实验设计问题：22 个会话只接收上一笔交易信息、只运行五轮，且未设置 ZI-C、启发式或同实验人类基线 [S06]。其“缺乏情绪/偏差”和“可用于高精度预测”等表述没有由该实验识别，不能进入本项目的证据结论。
- Dillion 等认为 LLM 可辅助先导研究和假设探索，但其训练来源、代表性和偏差限制其替代人类参与者 [R28]。
- Mou 等将领域分为个体、场景和社会模拟，并系统整理组件与评估方法 [R31]。
- Larooij 与 Törnberg 的综述把验证列为中心挑战 [R29]。AgentSociety 展示了超过 1 万 Agent 和 500 万次互动的工程规模，但仍是预印本，且“大规模”不能替代外部验证 [R30]。
- Xie 等以真实调查数据检验总体统计分布、相关关系、多变量预测和生命事件序列，发现异质性压缩 [R32]；Seshadri 等的跨地区用户研究发现模拟用户的鲁棒性、校准和公平性问题 [R33]。

### 3.6 区块链、token economy 与货币

- Cong、Li 与 Wang 的动态模型说明 token 价值、用户采用和平台激励存在反馈 [R34]；Davidson、De Filippi 与 Potts 把区块链理解为协调经济活动的制度技术 [R35]。
- Ferraciolli 与 Araújo 指出“货币涌现”ABM 与货币社会学仍连接不足 [R36]。该文是预印本，只能作为研究议程，不能视为已验证模型。
- Jiang 等把货币的“必要性”定义为：存在有货币可激励实现、而无货币不可实现的更优结果。其 312 人有限期货币实验显示，只有允许货币均衡的 Model M 中，货币才显著提高产出/福利；无建议时产出约 52%，有激励相容建议时约 62%，而无货币条件在早期后下降。没有货币均衡的 Model N 中，货币使用较低并随经验下降；改变角色持续和小组重复方式又会显著改变货币使用 [S07]。
- 该文同时说明，如果公开历史能支持信用和未来惩罚，货币可能不再必要；策略建议只有在激励相容时才明显有效，等待时间等界面细节还可能泄露局面信息 [S07]。**综合判断：**钱包不是社会模拟所必需的心理或社会组件。它对本项目的价值是稀缺资产所有权、预算约束、可验证结算和审计；是否需要货币必须相对于具体的双重需求巧合、承诺和信息摩擦来检验，不能由“接了链”倒推。
- 对话、记忆、画像、结构化理由和未成交意图应保留在链下。链上只保存需要共识的资产事件，必要时锚定实验日志哈希。把全部行为上链会增加隐私、成本、延迟和实验噪声。

## 4. “证据 → 设计”追踪矩阵

| 证据或论断 | 模拟构件 | 最小状态 | 行为规则 | 可观测指标 |
|---|---|---|---|---|
| 行动者嵌入关系 [R01,R03] | 类型化关系图 | 关系类型、信任、权力、互动历史 | 关系影响信息权重、匹配和合作 | 密度、同配性、信任变化 |
| 交换权力来自关系间依赖而非普通中心性 [S03] | 有条件交换网络 | 资源类型、正/负连接、替代伙伴、容量、排他性 | 一笔交换改变其他边的可行性/机会成本 | 议价剩余、替代率、节点移除后的最大流/福利 |
| 阈值与局部影响产生级联 [R02,R16] | 曝光/扩散引擎 | 采用阈值、邻居采用、曝光次数 | 超过阈值后考虑采用 | 采用曲线、级联大小、临界点 |
| 宏观结构反作用于个体 [R04] | 环境/制度状态 | 价格、规则、公共舆论、库存 | 每轮把公共状态加入可见上下文 | 结构变化前后行为差异 |
| 生成式解释不等于真实机制 [R05,R08] | 实验假设注册表 | 机制假设、替代机制、预期方向 | 每次实验只改变注册的干预 | 多模型解释、反事实差异 |
| 有限理性和异质性 [R11,R13] | Agent 决策层 | 偏好、预算、信息、启发式、目标 | 局部信息下的受约束选择 | 选择分布、违例率、适应速度 |
| 制度约束本身可产生高配置效率 [S02] | 拍卖/约束引擎与基线套件 | 私有价值、成本、预算、库存、订单簿 | ZI-U、ZI-C、启发式与 LLM 在同一规则下出价 | 配置效率、价格收敛/波动、剩余分布 |
| 规范需要执行与声誉 [R19-R23] | 规范/制裁引擎 | 规则、违规、声誉、惩罚成本 | 检测违规并允许制裁/申诉 | 合作率、违规率、惩罚率 |
| 联盟声誉依赖监测、信息流和集体排斥 [S04] | 声誉证据/成员边界 | 身份、证据来源、见证关系、成员资格、制裁范围 | 可核验报告更新公共声誉；违约造成未来机会损失 | 违约、雇佣溢价、排斥、跨群体成交、分割度 |
| 直接互惠强于同信息量的公共反馈 [S05] | 双层声誉与市场信任 | 双边历史、公开历史、最近负面事件、市场信任 | 负面/近期事件权重更高；反馈生产有成本 | 买入、发货、效率、反馈率、市场信任半衰期 |
| 记忆、反思、规划提高连贯性 [R24] | Agent 记忆层 | 事件记忆、摘要、计划、承诺 | 有界检索后产生结构化决定 | 计划完成率、承诺违约、记忆一致性 |
| LLM 有异质性压缩与偏差 [R29,R32,R33] | 校准与鲁棒性套件 | 真实基准分布、模型/提示版本 | 跨模型、跨提示、跨群体重复 | 分布距离、校准误差、群体误差 |
| 五轮 LLM 拍卖不能区分收敛、效率与学习 [S06] | 市场评估/记忆消融 | 全历史或上一笔、轮次、模型版本 | 比较记忆条件并做独立重复 | 效率、偏离、波动、数量、策略调整、置信区间 |
| 货币只在特定摩擦下必要 [S07] | 货币/信用机制对照 | 余额、公开历史、信用、承诺、匹配/角色状态 | 在 token、易货、赠与/信用、公共历史间随机处理 | 产出、福利、货币接受、信用违约、处理效应 |
| Token 采用与价值互相反馈 [R34] | 钱包/资产适配器 | 余额、资产、报价、结算状态 | 预算检查、原子结算、失败回滚 | 成交量、余额分布、失败交易 |

## 5. 推荐的 MVP 最小模型

### 5.1 必须有

1. **异质 Agent 状态**：身份/角色、资源与余额、稳定偏好、当前目标、有限信息、规范倾向、事件记忆和计划。人格文字只是这些变量的叙事层，不能替代结构化状态。
2. **有机制语义的关系/交换图**：每条边至少含关系类型、可交换资源、正/负连接、替代伙伴、容量/排他性、双边信任、最近互动和累计交易；公共声誉不得覆盖双边历史。允许事件改变边和其他交易机会 [S03-S05]。
3. **共享环境与制度引擎**：离散时间、市场、产品、公开信息、产权、预算、匹配、订单、交易、违约、制裁和结算规则。确定性约束应由代码/规则执行，而不是让 LLM 自行解释余额；Gode 与 Sunder 表明这些约束本身可能决定大部分配置效率 [S02]。
4. **事件状态机**：观察 → 检索有限记忆 → 提出结构化意图 → 规则校验 → 行动/交易 → 结算 → 更新关系与记忆 → 写日志。
5. **干预接口**：产品、价格、供给、广告/信息、政策或外部冲击必须是可版本化、可随机分配的实验变量。
6. **证据化声誉与制裁**：分别维护双边历史、公共反馈、证据来源/见证者、时效、身份持续、成员边界、申诉与制裁范围；至少记录市场层信任，避免把声誉实现成一个无来源总分 [S04-S05]。
7. **双层账本和可替换结算**：链下事件账本保存对话、报价、拒绝、理由和状态变化；Injective 测试网只结算需要资产所有权和共识的交易。Agent 可映射测试网地址，但钱包必须与 Agent 画像和市场机制分离，并可替换为链下 token、易货或信用条件 [S07]。
8. **可复现实验框架和基线套件**：固定初始人口与网络、随机种子、模型/提示/工具版本、对照组、多次独立运行、指标计算和失败日志；同一市场至少运行 ZI-U、ZI-C、确定性启发式和 LLM 四类基线 [S02,S06]。
9. **结构化决策记录**：记录目标、可见信息、候选行动、选定行动、置信度和简短理由；不得请求、保存或展示模型隐藏思维链。

### 5.2 可简化

- 单一产品、单一可替代资产、固定总供给和即时交割；只实现可与 token 对照的简化易货/公共历史信用，不做利息、抵押或复杂订单簿。
- 固定关系图和 3–6 类由真实或明确假设分布生成的画像；交换边仍须保留替代性、容量和直接/公共历史，先不让 Agent 自主创建组织。
- 固定制度规则，只允许信任、声誉、价格和关系变化。
- 只让 LLM 决定语义性选择；余额、库存、权限、匹配和指标均由确定性系统处理。
- 工程试验可从 24–50 个 Agent 开始；这是成本/演示启发式，不是文献证明的社会最小规模。统计判断依赖多次独立运行，而非单次大规模运行。

### 5.3 暂缓

- 万级 Agent、完全开放世界、自治政府、法规演化、公司创建、借贷和多币种宏观经济。
- 把完整对话、画像或“思想”写入公链；为所有行为强制分配钱包。
- 用 Agent 自报情绪替代可观察行为指标。
- 在没有真实人类或市场基准前输出销量、市场份额和价格的点预测。

## 6. 五个可证伪市场实验

| 实验 | 自变量 | 因变量 | 控制与基线 | 失败判据 |
|---|---|---|---|---|
| 产品采用与可核验口碑 | 播种位置、正/负消息、来源身份与证据可见性 | 采用率、达到 20% 采用时间、级联深度、错误信念存续期 | 同人口/网络/效用/价格；随机播种、无社交影响、无来源标签 | 策略排序跨模型频繁反转，或证据/来源处理不改变传播与购买 |
| 价格冲击与行为基线 | 价格水平、冲击幅度/持续期；Agent 类型 | 配置效率、成交量、价格偏离/波动、剩余分布、复购 | 同一订单簿运行 ZI-U、ZI-C、启发式、LLM；可加人类实验基准 [S02,S06] | LLM 未稳定优于 ZI-C/启发式却把高效率归因于 LLM，或只报均价不报分布和效率 |
| 直接关系、公共反馈与信任崩塌 | 固定伙伴/随机匹配、公开反馈、违约与反馈成本 | 买入率、发货率、效率、市场信任与恢复半衰期、反馈率 | 陌生人无历史、自动真实反馈、固定伙伴；再加入自愿反馈 [S05] | 直接与间接历史无差异，或负面事件不影响市场层信任，说明声誉状态未进入决策 |
| 交换网络权力 | 替代伙伴数、边的正/负连接、容量、移除关键节点 | 成交、议价剩余、拒绝率、位置收益、系统福利/最大流 | 度数相同但交换依赖不同的网络；普通中心性基线 [S03] | 权力只随 degree/betweenness 变化而不随交换机会变化，或节点移除不改变收益/流量 |
| 货币是否必要 | token、易货、无货币赠与、公共历史信用；承诺/信息摩擦 | 产出、福利、成交、货币接受、违约、财富集中 | 等值激励与相同匹配；有/无公开历史和角色持续条件 [S07] | token 不优于无货币可实施机制却宣称“链上货币效应”，或效果随提示建议而非激励相容性出现 |

每个实验至少报告效应分布、置信区间或自举区间、不同随机种子、不同 LLM/提示版本和关键消融。具体重复次数应通过先导方差与功效分析决定；不能用任意的“30 次”替代功效设计。

## 7. 校准与验证阶梯

1. **概念验证**：变量与社会学理论、市场定义和制度规则一一对应。
2. **实现验证**：守恒量、预算、库存、权限、订单有效性和状态机通过确定性测试；同种子可重放非 LLM 部分。
3. **微观验证**：用人类实验、调查或真实交易数据比较选择概率、响应异质性和条件效应。
4. **过程验证**：检查 Agent 是否依据允许信息行动；做无记忆、无关系、无规范、无 LLM 等消融。
5. **中观验证**：比较交换依赖、替代伙伴、议价权力、网络结构、扩散曲线、市场匹配、排斥与群体分化。
6. **宏观验证**：分别比较配置效率、价格收敛/波动、剩余与财富分布、市场信任、相关结构、时间序列和干预方向，不只匹配均值或均衡价 [S02,S05-S06]。
7. **外部验证**：在未参与校准的人群、产品或时间段上测试。
8. **鲁棒性**：跨随机种子、温度、提示措辞、模型供应商和版本测试；报告失败和不稳定结果。

最低基线应包括：ZI-U、ZI-C、固定启发式传统 ABM、无交换网络、无记忆、无规范/声誉、固定伙伴/随机匹配，以及链下积分、易货或公共历史信用替代链上 token。只有 LLM 模型稳定超过相应简单基线时，复杂性才有证据上的价值；“超过”必须对应事先声明的指标，不能用配置效率掩盖价格波动或分配失真 [S02]。

## 8. 主要争议与证据空白

- **分析单位争议**：个体主义便于实现和因果分解，关系取向更能表示身份与权力。MVP 应保留二者：Agent 是行动节点，关系事件是社会机制单位。
- **真实感与解释性冲突**：自然语言越丰富，行为越像人，但状态越难识别、校准和复现。
- **机制等价性**：多个微观规则可生成同一扩散或极化结果；宏观拟合不识别真实机制。
- **制度充分性与 Agent 智能**：双向拍卖约束可使随机 Agent 达到很高配置效率，却不能同时复制人类的价格稳定、学习和利润分配 [S02]。若不与 ZI-C 比较，LLM 的贡献不可识别。
- **网络测量误置**：普通社交中心性不等于交换权力；边的替代性和一笔交易对其他交易机会的影响才是机制变量 [S03]。
- **声誉的双重效应**：声誉和集体制裁既可降低欺诈，也可形成封闭联盟、排斥和市场分割 [S04]；公共反馈还存在信息生产与信任外部性，不能假定为免费的公共品 [S05]。
- **人口代表性**：画像提示可能改善条件平均值，却压缩尾部、交叉身份和少数群体差异 [R32-R33]。
- **模型污染**：LLM 可能记忆经典实验或训练语料，因此“重现实验”不等于独立产生同一行为机制 [R25-R27]。
- **链上行为效度**：测试网 token 通常没有现实机会成本；即使结算真实，偏好和风险承担仍可能是合成的。
- **货币必要性与技术混淆**：可验证钱包证明资产转移发生，不证明货币在该环境中不可替代。公共历史、信用或承诺机制可能实现同样或更高福利 [S07]。
- **缺少校准数据**：没有目标消费者的联合分布、关系网络、历史交易和真实干预响应，模型只能做机制探索和情景比较。
- **中文证据缺口**：本轮中文检索返回大量转载和付费文档页，未找到能同时核验原始元数据和结论、且直接回答本问题的中文核心论文，因此未用二手页面补足数量。

## 10. 结论

MVP 应把“社会”实现为一套可观察的关系与交换状态转移系统，而不是一组会聊天的角色。最小充分架构是：异质 Agent、有条件交换机会与关系图、共享环境、制度约束、双边/公共信息与声誉、事件和可替换结算，以及实验/验证层。LLM 最适合承担受约束的语义决策和交流；社会事实、预算、资产和规则应由外部系统维护。钱包是结算实现之一，不是社会或市场的最小本体单位。

在获得真实目标人群、关系网络、交易和干预数据之前，该系统最适合**机制探索、假设生成、极端情景测试和相对方案比较**。它不具备可信的现实市场点预测能力。达到定量预测至少还需要：代表性人口联合分布、真实网络或可辩护生成模型、行为实验/交易校准数据、时间序列、外部验证样本、跨模型鲁棒性和预注册的成功/失败标准。
